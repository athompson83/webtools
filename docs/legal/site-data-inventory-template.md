# Site Data Inventory Template

Complete one copy for every production site before enabling analytics, advertising, forms, uploads, personalization, or affiliate tracking.

## Identity

- Site name:
- Production domain:
- Legal operator:
- Contact email:
- Privacy contact:
- Jurisdiction/counsel notes:

## Data collected directly

Record every form field, upload, identifier, or user-provided value. For each item document:

- purpose
- whether required
- storage location
- retention period
- deletion method
- third parties receiving it

## Passive/technical data

Document:

- IP handling
- cookies
- local storage
- analytics identifiers
- advertising identifiers
- server logs
- consent records

## Third parties

For each provider document:

- provider name
- purpose
- data shared
- country/region implications
- contract/DPA status where relevant
- whether consent is required before activation

- networks/partners:

- disclosure locations:
- sponsored-link attributes:

## User rights

Document the operational process for:

- access
- deletion
- correction
- opt out of sale/share where applicable
- cookie/consent withdrawal

## Publication gate

The privacy policy, cookie policy, terms, advertising/affiliate disclosure, and any opt-out controls must reflect this inventory. Do not publish generic legal text that describes practices the site does not actually follow.
